## 🌐 HTML, CSS e JavaScript

- **HTML:** estrutura da página  
- **CSS:** estilo e layout  
- **JavaScript:** interatividade  

------------------------------------------------------------------------

## 🧱 HTML (Estrutura)

- Linguagem de marcação  
- Uso de tags para organizar conteúdo  

### 🔹 Tags principais
- `<html>`, `<head>`, `<body>`  

### 🔹 HTML5
- Novas tags semânticas  
- Melhor organização do conteúdo  

------------------------------------------------------------------------

## 🏗️ Estrutura Semântica

- `<header>` → cabeçalho  
- `<footer>` → rodapé  
- `<section>` → seção  
- `<article>` → conteúdo independente  
- `<nav>` → navegação  
- `<aside>` → conteúdo auxiliar  

------------------------------------------------------------------------

## 📝 Elementos HTML

### 🔹 Texto
- `<h1>` até `<h6>`  
- `<p>` parágrafos  
- `<br>` quebra de linha  

### 🔹 Mídia
- `<img>` → imagens  
- `<video>` → vídeos  
- `<audio>` → áudio  

### 🔹 Links e Listas
- `<a>` → links  
- `<ul>` / `<ol>` → listas  

### 🔹 Tabelas
- `<table>`, `<tr>`, `<td>`  

### 🔹 Formulários
- `<form>`, `<input>`, `<textarea>`  

------------------------------------------------------------------------

## 🎨 CSS (Estilo)

- Define aparência da página  

### 🔹 Estrutura
seletor { propriedade: valor }

### 🔹 Formas de uso
- Inline  
- Interno  
- Externo (recomendado)  

### 🔹 Propriedades
- color  
- background  
- font-size  
- margin / padding  
- border  
- width / height  

------------------------------------------------------------------------

## 🧠 JavaScript

- Linguagem de programação do navegador  
- Responsável pela interatividade  

### 🔹 Usos
- Manipular HTML  
- Validar formulários  
- Atualizar conteúdo  
- Comunicação com servidor  

------------------------------------------------------------------------

## 🔢 Variáveis

- `var` → escopo global/função  
- `let` → escopo de bloco  

------------------------------------------------------------------------

## 🔀 Condicionais

- `if`, `else`, `else if`  
- Executa código baseado em condições  

------------------------------------------------------------------------

## ⚙️ Funções

- Blocos de código reutilizáveis  

### 🔹 Exemplos
- console.log()  
- alert()  
- getElementById()  
- addEventListener()  

------------------------------------------------------------------------

## ⚡ Eventos

- Ações do usuário (clique, teclado, etc.)

### 🔹 Funcionamento
1. Evento ocorre  
2. Listener detecta  
3. Função executa  
4. Página é atualizada
