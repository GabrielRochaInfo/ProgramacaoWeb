## 📋 Escopo e Backlog do Projeto

### 🔹 Importância do Escopo

- Define objetivos do projeto  
- Alinha equipe e stakeholders  
- Facilita organização do desenvolvimento  
- Melhora a gestão do backlog  

### 🔹 Elementos do Escopo

- Descrição do projeto  
- Funcionalidades principais  
- Público-alvo  
- Tecnologias utilizadas  
- Objetivos do sistema  

### 📌 Exemplo de Escopo

Desenvolvimento de um site institucional com:

- Homepage atrativa  
- Página "Sobre"  
- Blog  
- Formulário de contato  
- Design responsivo  
- Uso de HTML, CSS, JavaScript e CMS  

------------------------------------------------------------------------

## 🗂️ Planejamento e Gestão do Backlog

### 🔹 Benefícios

- Melhor comunicação entre equipe e cliente  
- Organização das tarefas  
- Estrutura clara de desenvolvimento  

### 🔹 User Stories

Formato:
> Como (quem?), eu quero (o que?) para (por que?)

### 📌 Exemplo

> Como visitante, eu quero acessar a página "Sobre" para conhecer melhor a empresa.

## 🧩 Wireframes: Estruturando o Site

### 🔹 O que são?

Representações visuais da estrutura do site.

### 🔹 Tipos

- Baixa fidelidade (simples)  
- Alta fidelidade (detalhado)  

### 🔹 Objetivos

- Planejar layout  
- Melhorar usabilidade  
- Validar ideias antes do desenvolvimento  

------------------------------------------------------------------------

## 🎨 Ferramentas de Prototipação

- Figma  
- Uizard  

### 🔹 Recursos

- Criação a partir de imagens e prompts  
- Uso de plugins (ex: html.to.design)  
- Iteração e validação de ideias  

------------------------------------------------------------------------

## 📝 Atividade

1. Pesquisar aplicações web similares  
   - Identificar pontos fortes e fracos  

2. Analisar a estrutura da aplicação  
   - Componentes  
   - Navegação  
   - Arquitetura  

3. Criar 3 user stories no formato padrão  

4. Desenvolver wireframes das telas principais  

5. Criar um quadro Kanban (Trello)  
   - Listar tarefas  
   - Acompanhar progresso
