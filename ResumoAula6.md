## 🧩 Website Builders

### 🔹 O que são?
Ferramentas para criar sites sem programação.

### 🔹 Características
- Interface visual (drag-and-drop)  
- Templates prontos  
- Criação rápida  

------------------------------------------------------------------------

## ⚖️ CMS vs Website Builder

### CMS
- Mais flexível  
- Maior controle  
- Requer configuração  

### Website Builder
- Fácil de usar  
- Tudo em um (hospedagem + editor)  
- Menos personalização  

------------------------------------------------------------------------

## ⚙️ Funcionalidades

- Templates e temas  
- Editor visual  
- Responsividade  
- SEO integrado  
- E-commerce  
- Hospedagem inclusa  

------------------------------------------------------------------------

## 🏢 Tipos de Solução

### 🔹 Hospedada
- Tudo pronto  
- Sem necessidade de configuração  

### 🔹 Auto-hospedada
- Maior controle  
- Requer configuração manual
