# Loja Fictícia Rocha.info

Esta é uma loja fictícia criada como atividade acadêmica utilizando um Website Builder (Google Sites).  
O objetivo é demonstrar o uso de ferramentas de criação de sites sem programação, personalização de layout e elementos interativos.

## Ferramenta utilizada
- **Website Builder:** Google Sites.
- **Tipo:** Drag-and-Drop (editor visual).
- **Inteligência Artificial:** Não possui IA avançada.
- **Motivo da escolha:** 100% gratuito, fácil de usar e rápido para criar páginas funcionalmente completas.

## Estrutura do site
O site possui as seguintes páginas:

1. **Home / Página Inicial**  
   - Apresenta os produtos fictícios com imagens, descrição e botão “Comprar”. 

2. **Contato**  
   - Página com formulário do Google Forms para envio de mensagens.  
   - Formulário inclui campos: Nome, Email, Escolha do produto. 

## Link do site
- [Acesse a Loja Rocha.info](https://sites.google.com/view/rocha-info)

## Observações
- Todas as funcionalidades são simuladas para fins acadêmicos.  
- O botão “Comprar” leva para a página com um formulário de contato e registra respostas no Google Forms.
